# dotfiles 🛠️

Mis configuraciones: emuladores, Minecraft, terminal, agentes de IA y lo que fui aprendiendo en Linux. Úsalas, cópialas o mejóralas.

| Carpeta | Qué hay |
|---|---|
| [`emuladores/eden`](emuladores/eden) | Config de Eden (Switch): Vulkan, 1.5x, mando y teclado |
| [`minecraft`](minecraft) | Lista de mods del modpack *Distantly Optimized v7* (Fabric 1.21.11) para PrismLauncher |
| [`powershell`](powershell) | Perfil de PowerShell con atajos (`medusa`, `jarvis`, `hermes`) y UTF-8 |
| [`opencode`](opencode) | Tema **medusa-blue** para la TUI de OpenCode |
| [`linux-hyprland`](linux-hyprland) | Notas y fixes de Hyprland 0.56 en Arch |
| [`git`](git) | `.gitignore` global |

## Reglas de este repo
- **Sin claves, tokens ni contraseñas.** Todo se revisa antes de subir.
- **Sin keys, firmware ni ROMs** de consolas: tienen derechos de autor y GitHub los retira por DMCA. Aquí solo van ajustes.
- Las rutas personales se cambian por `%APPDATA%` o variables.
