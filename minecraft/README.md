# Minecraft: modpack Distantly Optimized v7 (Fabric 1.21.11)

`distantly-optimized-v7-mods.txt` es la lista de los 124 mods de mi instancia en PrismLauncher (solo nombres y versiones; los `.jar` se bajan de Modrinth o CurseForge).

Consejo que me costó aprender: si un mod hace crashear el juego, revisa primero que todos sean de la misma versión de Minecraft y de Fabric Loader, y que tengas Java 21.
